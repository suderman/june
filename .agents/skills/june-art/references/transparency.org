** Eight-node extraction graph
| ID | Node | Connection |
|----+------+------------|
| 1 | LoadImage | Original RGB, for example June/production-idle/idle-attentive-s4002_00001_.png [output] |
| 2 | LoadBackgroundRemovalModel | toonout-fp16.safetensors |
| 3 | RemoveBackground | image 1 and model 2, produces foreground-probability MASK |
| 4 | MaskToImage | mask 3 to inspectable grayscale IMAGE |
| 5 | SaveImage | Native foreground mask PNG |
| 6 | InvertMask | 1 minus foreground mask |
| 7 | JoinImageWithAlpha | Original image 1 and inverted mask 6 |
| 8 | SaveImage | Source-size RGBA PNG |

=RemoveBackground= gives 1 for foreground. ComfyUI =JoinImageWithAlpha= expects a transparency mask, where 1 means transparent, so inversion is required. The final PNG alpha is the original foreground mask. Omitting inversion produces the opposite cutout. Native 8-bit PNG alpha equals the saved grayscale mask. Keep both native outputs, their API history and workflow; extraction is not another diffusion or face-replacement pass.

Use separate prefixes and source names for each candidate. Native loading supports =... [output]= references; do not modify source files. Use the same frontend/API execution and success checks as generation, reading actual node schemas for current input names.

** Pixel and color checks
Preserve original RGB even beneath transparent pixels. Alpha is genuine when corners are zero, silhouette interiors near 255 and edge samples graded, not when an image merely depicts a checkerboard. These commands inspect an existing extraction without altering it:

#+begin_src sh
magick identify -format '%wx%h %[channels] %[colorspace]\n' "$RGBA"
magick "$RGBA" -alpha extract -format 'min=%[min] max=%[max] levels=%k\n' info:
cmp <(magick "$RGB" -alpha off -depth 8 rgb:-) <(magick "$RGBA" -alpha off -depth 8 rgb:-)
cmp <(magick "$MASK" -colorspace gray -depth 8 gray:-) <(magick "$RGBA" -alpha extract -depth 8 gray:-)
#+end_src

Here =RGB=, =RGBA= and =MASK= are explicit paths you selected; use bash for process substitution. The approved archive names are =production-idle/candidates/idle-attentive-s4002.png=, =production-idle/idle-attentive-source-alpha.png= and =production-idle/idle-attentive-mask.png=. The latter two are source-size 1024x1344, not the final 2048x2662 asset. =idle-attentive-processed-mask.png= instead describes final normalized alpha.

Use sRGB output. Inspect actual PNG chunks/profile, not just ImageMagick's inferred colorspace. Source RGB was already sRGB; declaring its sRGB intent can be a metadata-only operation that preserves IDAT/pixels. Historical reference-sheet builders insert an sRGB chunk explicitly because =png:include-chunk=sRGB= did not actually emit one in this environment. For a new file requiring only that declaration, use a separate output path, PNG intent byte 0 and correct CRC after IHDR; verify decoded pixels unchanged with the inspector. Do not recolor source RGB, rewrite approved files, or confuse a metadata tag with conversion from a genuinely different color space. Keep untouched native PNGs with embedded prompt/workflow even if a separate tagged copy is made.

Ingestion's lossless WebP retains alpha. Transparent RGB may be normalized by =webp:exact=false= and upscale/placement changes source pixels, so compare final PNG to decoded final WebP, not final output to raw generation. Compare source alpha RGB to raw generation separately. Original ComfyUI PNGs remain the provenance source.

** Review over four grounds
Create NEW preview files, never flatten the deliverable. For example, with =RGBA= pointing at the source or final PNG and =OUT= an unused PNG path:

#+begin_src sh
magick "$RGBA" -background white -alpha remove -alpha off "$OUT"
# Repeat to different OUT paths with '#101018' and '#2058E0'.
#+end_src

Also composite over a representative room/panel background from the actual application. Inspect at ordinary panel size and enlarged edges: hair wisps/bangs, headset band and earcups, microphone boom, collar/blouse, dark skirt contours, fingers/hand gaps and held-prop holes. Check for lost lines, opaque background islands, pale halos and partially erased skin. Sample known source coordinates carefully; a point outside an earcup is not evidence of an erased earcup.

Idle source has no hands in the finished crop. Its successful matte does not validate future finger gaps. Later isolated-prop tests preserved the mug-handle and clipboard-ring holes; those do not establish hand anatomy either. Bright RGB hair highlights remain opaque by design. Avoid default erosion, hard thresholding, aggressive defringing and hair-color removal. Correct a material failure only after a source/mask/background comparison demonstrates it and the change has a reviewable before/after.

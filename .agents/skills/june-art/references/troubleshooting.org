** Service, workflow and frontend failures
- Proxy timeout is not proof of GPU/service failure. Check loopback =/system_stats=, queue and service logs. Do not change DNS, Traefik or restart ComfyUI under a normal art request.
- Fresh frontend may not yet have =app.canvas= or graph ready. Wait for visible Run/app initialization, then load a separate graph. A failed graph load before queuing does not count as a render.
- Node missing: inspect =/object_info= and installed plugin commit, model filename options and backend logs. The reference adapter requires its custom node; native RemoveBackground does not require another custom node. Do not replace Anima with a convenient unrelated model.
- Node inputs can change. Verify names/types via object_info. Saved UI widgets and API prompt are distinct formats. Clear inherited =widgets_values_named= in a cloned UI graph; stale named values caused unexpected parameters.
- LoadImage preview can require its widget callback. CropV2 had separate numeric and crop_region state; callbacks kept them synchronized. Native production generation does not need those early masked-crop graphs.
- Saving a named graph does not prove it contains the intended values. Fetch the saved JSON and compare to the archived/exported version. Never overwrite original experiments as a convenience.
- UI queue submission or a prompt_id does not prove success. Require history status and output PNG, inspect metadata and image. Do not queue another render merely because Vue preview restoration helpers are unavailable.
- Screenshot tools sometimes timed out while actual graph/API/upload/run controls worked. Read the generated PNG directly or retrieve the output URL. Do not turn an inspection timeout into an installation repair.
- Pillow was absent on kit; standard-library PNG parsing and installed ImageMagick handled metadata/pixels. Avoid installing an image library for an already solved read-only check.

** Alpha and ingestion failures
- Inverse cutout: RemoveBackground returns foreground; JoinImageWithAlpha takes transparency. Use InvertMask once, then verify final alpha equals saved foreground mask.
- Checkerboard image is not alpha. Check zero-alpha corners/interiors and inspect against several grounds. General BiRefNet's pale fringe was worse than ToonOut on June; accepted ToonOut edges need no destructive default cleanup.
- Missing fine feature: compare source RGB and native foreground mask, sample actual source coordinates, enlarge headset boom/fingers/holes and inspect final panel size. Do not erode the whole silhouette to fix a few bright pixels.
- Huge source face or clipped sides: ingester scales by measured face, not a generic bounding box. Recheck cheek/hairline/chin measurement and source composition; an overly wide figure is warned about, not automatically fixed.
- Mouth outside face: both normalized arrays use the entire canvas. Supply source-pixel mouth with --mouth; never treat it as face-relative or put source pixels directly in final manifest geometry.
- Empty marks array fails validation: omit marks or provide valid application-rendered marks. A full framing chooses tall canvas. Check sidecar metadata before interpreting an ingest error as bad image pixels.
- Zero planned assets with most inventory unproduced is expected when planned.json is absent. Status never parses art-list.org. Sidecar-driven ingestion and runtime fallback merging work without that catalogue. Do not populate it or modify the renderer just to change the count.
- Incoming disappeared after success: normal. Source PNG was copied, sidecars moved, incoming PNG consumed. Work from independent archived sources, not the last incoming copy.
- Existing production name: ingest can overwrite it. Stop for explicit replacement coordination. A new staging proof is the correct place for replay tests.
- Blank WebP/QML or missing effects: verify matching Qt image-format plugin and imports. QT_QPA_PLATFORM=offscreen omitted shader layers in one proof. Use isolated Xvfb/OpenGL before declaring an asset defect; do not alter the application to pass the image.

** Evidence to retain when blocked
Keep the exact error, live node schemas/versions, submitted API graph, UI workflow, input identities, model hashes, prompt ID/history, original PNG, alpha mask and relevant manifest/geometry. State what is unverified once. Do not install speculative fixes, silently accept a different June or expand the authorized batch because a trial failed. Report the smallest demonstrated next experiment and get approval when it changes scope.

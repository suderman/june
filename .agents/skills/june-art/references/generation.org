** Direct HTTP execution, only with generation authorization
The same API graph can run without the browser. First check =/queue=. Prepare a new record directory and extract the original metadata as above. This example submits a job; do not run it during a documentation audit.

#+begin_src python
import json, os, urllib.request, uuid
from pathlib import Path
base = os.environ.get('COMFY', 'http://127.0.0.1:8188').rstrip('/')
replay = Path(os.environ['REPLAY'])  # NEW extraction directory chosen above
prompt = json.loads((replay / 'prompt.json').read_text())
workflow = json.loads((replay / 'workflow.json').read_text())
prefix = 'June/replays/idle-attentive-s4002'
prompt['11']['inputs']['filename_prefix'] = prefix
for node in workflow['nodes']:
    if str(node['id']) == '11':
        node['widgets_values'][0] = prefix
        node.pop('widgets_values_named', None)
body = {'prompt': prompt, 'client_id': str(uuid.uuid4()),
        'extra_data': {'extra_pnginfo': {'workflow': workflow}}}
request = urllib.request.Request(base + '/prompt', data=json.dumps(body).encode(),
                                 headers={'Content-Type': 'application/json'})
with urllib.request.urlopen(request) as response:
    result = json.load(response)
print(result)  # retain prompt_id, number and any node_errors
#+end_src

The example synchronizes the UI SaveImage widget with the API prefix so embedded metadata describes the new path. Persist both submitted graphs and response. A returned prompt_id is not success. Poll =GET /history/PROMPT_ID= until present, then require status_str to be =success= and completed to be =true=. Read all failure messages before retrying. Save history JSON and the output descriptors from =outputs["11"].images=. Retrieve each through =GET /view?filename=...&subfolder=...&type=output=, using URL encoding, or its host output path. Counters may increment; never guess the resulting filename. Do not queue extra renders solely to restore a preview.

Embedded executed prompt can include a backend =is_changed= cache field on LoadImage nodes. When comparing PNG prompt to submitted/history prompt, remove only that top-level field per node, not class names or inputs. Record hashes of originals, references, submitted graphs, workflow exports, masks and normalized output, with model hashes, custom-node commit, endpoint versions and runtime. A selected filename without this provenance is not a reproducible record.

** Generate a new named expression
Read its exact =art-list.org= entry. For example =skeptical-raised-eyebrow= maps to expression =skeptical=, frontal, one eyebrow up, folded arms and flat mouth. Pilot names like mischievous amusement are study labels, not new expression identifiers.

Clone the isolated production generator or conversational baseline as appropriate, with a new workflow UUID/name. Retain canonical board/model stack. Replace scene-specific positive text with the requested pose/acting/facing and plain neutral background for sprites. Replace conflicting negatives too: idle's negative includes raised arms, crossed arms and visible hands, which must not fight an arm-folding or gesture asset. Keep quality/anatomy/decorations/duplication negatives. A short quality prefix plus scene/acting tags and precise composition usually worked better than repeatedly redescribing June.

Use explicit above-knee skirt wording when legs are visible; remove inherited knee-length or jeans instructions rather than append conflicting text. Do not request alpha through text alone: generate a coherent isolated silhouette, then segment. Avoid colored key backgrounds that may contaminate edges. Neutral pale backgrounds worked with ToonOut, though warm hair highlights remain part of RGB.

A six-generation matched-seed turned-head comparison in =$ART/production-standard-batch-1/= did not establish a reliable profile fix. Wording for softly rounded cheeks, a compact lower face and a tiny simplified anime nose preserved identity best in frontal/shallow views. Strong profile wording still produced prominent noses and often reversed direction. Shallow-angle wording also changed the actual angle, so do not call its smaller nose a same-angle improvement. These tests kept canonical conditioning unchanged; they establish no reference-board improvement. Judge actual direction, cheeks and nose against canon before attractiveness. Do not flatten the face or silently mirror it to meet an inventory direction.

Honor the authorized batch cap, record independent seeds, review complete images and enlarged faces/hands, and present rejects as well as selections. Matched-seed experiments change one factor at a time; independent seeds test repeatability. Do not claim consistency from one lucky render. Obtain review, then follow transparency and staging/ingestion checks. Exact angle control remains weak; consult troubleshooting before spending another camera-angle batch.

#+TITLE: June

June is a personal assistant: one persistent daemon on Pi Durable. You talk to her from a terminal client, a desktop overlay, an Android app, or Telegram. She reads Org for tasks and knowledge and Herdr for live agent sessions. She does quick checks and small edits herself with a shell and file tools, and hands larger work to coding agents through an Org dispatcher.

* Built on
- [[https://github.com/earendil-works/pi/tree/main/packages/durable][Pi Durable]]: the harness June runs in. Her conversation, tasks, tools, and compaction are durable, so a restart resumes work rather than losing or repeating it. [[https://github.com/earendil-works/pi/tree/main/packages/ai][pi-ai]] talks to the models and [[https://github.com/earendil-works/pi/tree/main/packages/tui][pi-tui]] draws the terminal client.
- [[https://github.com/earendil-works/pi/tree/main/packages/coding-agent][Pi Coding Agent]] and Claude Code: the agents the dispatcher starts for AUTO tasks, selected by =AGENT=. June reads her providers from Pi's =models.json=.
- [[https://herdr.dev][Herdr]]: the runtime those agents run in, one pane each. June reads their status through its CLI.
- [[https://orgmode.org][Org]] in [[https://www.gnu.org/software/emacs/][Emacs]]: where tasks, projects, calendars, and June's own files live. Task states and dates are set by Org itself, through Emacs in batch.
- [[https://github.com/BurntSushi/ripgrep][ripgrep]]: how June searches Org.

* Getting started
June is packaged for Nix, with a Home Manager module for the daemon and clients. [[file:docs/development.org][docs/development.org]] covers installing and deploying her.

#+begin_src sh
june init [NAME]     # copy the starting files into place
june doctor          # configuration and dependency checks
june                 # terminal client attached to the conversation
june ask "What are my agents doing?"
june status --json   # daemon, model, and conversation state; no model call
#+end_src

June has one conversation, shared by every client. Detaching or losing the connection never stops her work.
